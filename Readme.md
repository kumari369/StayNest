# 🏡 StayNest

A full-stack accommodation web application that allows users to discover, search, and manage stays through an interactive web interface.

## 🌐 Live Demo

[Visit StayNest](https://staynest-woxh.onrender.com)

## 📌 About the Project

StayNest is a full-stack web application developed to provide a simple platform for exploring and managing accommodation listings.

The project focuses on implementing real-world web development concepts such as server-side rendering, database management, user interaction, search functionality, image handling, and RESTful backend development.

## ✨ Features

- 🔐 User authentication
- 🏠 Create and manage accommodation listings
- 🔍 Search and explore listings
- ✏️ Edit and delete listings
- ⭐ Review and rating functionality
- 🖼️ Image upload and management
- 📱 Responsive user interface
- 🗄️ MongoDB database integration
- 🔒 Protected routes and authorization
